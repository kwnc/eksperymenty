# NoteNest - Local MVP Note-Taking Application

A local-first note-taking application built with vanilla HTML, CSS, and JavaScript. NoteNest is a complete, production-ready MVP that works entirely offline with no external dependencies.

## 🚀 Quick Start

1. **Download**: Clone this repository or download the ZIP file
2. **Open**: Double-click `index.html` or open it in your web browser
3. **Register**: Create your account (stored locally)
4. **Start Writing**: Begin creating and organizing your notes immediately

No installation, no setup, no internet connection required!

## ✨ Features

### Core Functionality
- 🔐 **Local Authentication**: Secure user accounts with encrypted passwords
- 📝 **Rich Text Editing**: Full-featured note editor with formatting
- 📁 **Notebook Organization**: Organize notes into color-coded notebooks
- 🔍 **Smart Search**: Full-text search with tag support
- 📤 **Export Options**: PDF, Markdown, and JSON backup exports
- 🌙 **Dark Mode**: Beautiful light and dark themes
- ⌨️ **Keyboard Shortcuts**: Efficient navigation and editing

### Advanced Features
- 💾 **Auto-save**: Never lose your work with automatic saving
- 🏷️ **Tag System**: Organize with hashtag-style tags
- 📱 **Responsive Design**: Works perfectly on desktop and mobile
- 🔒 **Offline First**: Complete functionality without internet
- ⚡ **High Performance**: Fast loading and smooth interactions
