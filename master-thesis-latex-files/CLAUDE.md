## Project Overview

This is a master's thesis repository for a project titled "Eksperymenty z systemami wieloagentowymi do tworzenia aplikacji biznesowych" (Experiments with multi-agent systems for creating business applications). The thesis investigates the role of AI agents in software development through experiments evaluating their usability, performance, and impact on software quality.

## Repository Structure

- `main.tex` - Main LaTeX document file (uses ee-thesis document class from Warsaw University of Technology)
- `bibliografia.bib` - BibLaTeX bibliography file (uses biber backend)
- `tex/` - Chapter files:
  - `1-wstep.tex` - Introduction
  - `2-modele-jezykowe.tex` - Language models chapter
  - `3-narzedzia.tex` - Tools chapter
  - `4-eksperymenty.tex` - Experiments chapter (documents three experiments with single-agent, dual-agent architect-programmer, and multi-agent autonomous systems)

  - `7-code-listings.tex` - Code listings appendix
- `img/` - Images and figures directory
- `portal-dla-serwisu-samochodowego/` - The actual implementation project (React/TypeScript application for car service management described in `5-implementacja.tex`. Project is generated by the multiagent system)
- `agent*_logs.pdf` - PDF logs from agent experiments

## Experimental Results Structure

The experiments chapter (`tex/4-eksperymenty.tex`) contains three experiments, each evaluating three scenarios:
- **Scenario 1**: Single agent
- **Scenario 2**: Architect-programmer dual agent system
- **Scenario 3**: Autonomous multi-agent system

Each experiment evaluates generated applications in four categories (scale 1-5):
- Functionality
- User interface
- Aesthetics
- Lack of errors

Key findings: Multi-agent systems excel with detailed specifications; single agents are sufficient for simple tasks without specifications.

## Implementation Case Study

The implementation chapter (`tex/5-implementacja.tex`) documents a real-world car service management portal (Autotu) created using a multi-agent system configuration (Manager, Architect, Programmer, Reviewer) powered by Claude Opus 4. The implementation:
- Took 5 hours 40 minutes with 35 user commands and 124 inter-agent messages
- Used React 18, TypeScript, Vite, Zustand, TanStack Query, Tailwind CSS
- Achieved 84% test coverage
- Produced 52 source files (20 UI components, 11 domain modules, 8 test files)
- Integrated with external services (Supabase, Google Workspace, Twilio, VIN lookup)
