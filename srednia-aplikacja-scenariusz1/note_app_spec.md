# Local MVP Spec Document

# **App Name**: NoteNest

## Core Features:

* **Note Creation & Editing**: Users can create and edit basic text notes. Each note consists of a title, body content, and optional tags. Notes are stored locally in the browser or in-memory (no backend required).
* **Tagging**: Users can add one or more tags to each note to help categorize and filter notes.

## Style Guidelines:

* **Primary color**: Orange (#E97900) for buttons and highlights.
* **Secondary color**: Light gray (#ECEFF1) for background.
* **Typography**: Simple and readable sans-serif fonts.
* **Layout**: Minimalist design with a single-column view for creating and viewing notes.
* **UX Enhancements**: Instant feedback when a note is created or edited (e.g., toast notification or subtle animation).

## Problems Being Solved

* Need for a quick, distraction-free space to jot down notes.
* Ability to categorize and quickly find notes using tags.
* Avoiding the complexity of user accounts or online syncing.
* Providing a simple app for short-term or lightweight note-taking tasks.

## User Roles

* **User**: Can create and edit basic notes with tags without the need for registration or login.

## User Stories

### User

* As a user, I want to open the app and immediately start typing a note.
* As a user, I want to create a new note with a title and content.
* As a user, I want to add tags to a note to help organize it.
* As a user, I want to filter or browse notes by tag.
* As a user, I want to edit a previously created note.
* As a user, I want the app to remember my notes and tags temporarily without requiring me to sign up.
